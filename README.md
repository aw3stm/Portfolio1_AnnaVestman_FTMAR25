## Description
This project was part of the Portfolio 1 course at Noroff. 
The goal was to design and develop a personal portfolio website from scratch to showcase my frontend development skills, completed projects, and my journey as a developer.

**Key Objectives:**
* Responsive design
* Interacvtive UI
* Cleand and semantic code
* Professional showcase

## Built With
* Figma
* HTML
* CSS3 (Flexbox, Grid, Custom Properties/Variables)
* Vanilla JavaScript (DOM manipulation, Event Listeners)

## Features
* Sticky navbar with frosted-glass design that stays visible while scrolling.
* Fully accessible hamburger menu
* Interactive project cards
* Smooth scrolling

## Getting Started

### Installing

1. Clone the repo:

```bash
git clone https://github.com/aw3stm/Portfolio1_AnnaVestman_FTMAR25.git
```

2. Install the dependencies:

```
npm install
```

### Running
To run the app, run the following commands:

```bash
npm run start
```
